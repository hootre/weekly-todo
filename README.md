# 위클리 · 주간 할 일 보드

할 일을 **요일로 끌어다 놓고**, 매일 체크하는 모바일 우선 주간 TO-DO 웹앱입니다.
크롬/사파리에서 바로 쓰고, 홈 화면에 추가하면 앱처럼 동작합니다(PWA).

## 기능
- **일정 종류 색**: 촬영 🔴 · 편집 🔵 · 개인 🟢. 다크 화면 기준으로 잘 보이게 색을 입혔어요(설정에서 라이트/자동 가능).
- **주간 / 월간 보기**: 상단 `주 | 월` 전환. 월간에서도 날짜 칸에 끌어다 놓으면 배정, 날짜를 누르면 그날 목록·체크·추가.
- **구글 캘린더 연결 (읽기 + 추가만)**: `google-apps-script/Code.gs`를 웹앱으로 배포하고 설정에 주소·비밀키를 넣으면
  - **내 일정 색**(기본 1번 라벤더 = 보라미디어 캘린더의 '동준' 색)으로 칠해진 일정과 **키워드**(기본 `동준`)가 제목에 든 일정을 전부 가져와요.
  - `+ 추가 → 📅 구글 캘린더 일정`으로 넣은 일정은 구글 캘린더에 내 일정 색으로 바로 들어가요.
  - 수정·삭제 코드는 스크립트에 아예 없어서 구글 캘린더 일정이 지워질 일이 없어요.
- **미배정 할 일 트레이**: 아직 요일에 배정 안 된 작업이 위에 칩으로 쭉 뜹니다.
- **드래그 앤 드롭**: 칩을 길게 눌러 요일 카드나 상단 요일 스트립(월~일)에 놓으면 배정. 요일끼리 이동, 다시 트레이로 되돌리기 가능.
- **탭해서 배정**: 칩을 누르면 요일 버튼으로 바로 배정(여러 날 선택 가능).
- **매일 체크**: 요일별 체크 + 주간 진행률 바. 오늘 할 일을 다 끝내면 축하 알림.
- **진행 상태**: 기획 · 촬영 · 편집 · 수정대기 · 완료, **오케이(컨펌)** 표시, 프로젝트 색상/필터.
- **그날 목표**: 배정된 칸마다 "완료", "완성", "기획" 같은 목표 메모.
- **한 번에 추가**: `교촌 DID (편집) 오케이` 형식의 여러 줄을 붙여넣으면 프로젝트/상태/오케이 자동 인식.
- **지난 미완료 가져오기**: 지난 날 못 끝낸 일을 한 번에 오늘로.
- **휴식일 · 요일 메모 · 주간 메모**.
- **캘린더 일정 표시**: 가져온 일정은 해당 날짜에 표시되고, 다가오는 일정은 D-day와 함께 트레이에 떠요. 끌어다 놓으면 "준비" 일정이 됩니다. (연결 스크립트 없이 iCal 비공개 주소로도 가져올 수 있지만 iCal에는 색 정보가 없어 키워드로만 골라요.)
- **실시간 동기화**: 폰과 PC에서 동시에 열어도 바로 반영(Supabase Realtime).
- **멤버 승인**: 처음 가입한 사람이 관리자. 이후 가입자는 관리자가 승인해야 보드 접근 가능.

## 구조
정적 사이트(빌드 없음) + Supabase.

```
index.html          화면
css/app.css         스타일 (라이트/다크)
js/app.js           앱 로직
js/config.js        Supabase URL / publishable(anon) 키
vendor/             supabase-js, SortableJS
supabase/schema.sql DB 스키마 (테이블 · RLS · 트리거 · 캘린더 함수)
sw.js, manifest     PWA
```

## 새로 설치할 때
1. Supabase 프로젝트 생성 → **SQL Editor**에 `supabase/schema.sql` 붙여넣고 Run.
2. **Authentication → Sign In / Providers → Email**에서 *Confirm email* 끄기(선택), **URL Configuration**의 Site URL을 배포 주소로.
3. **Project Settings → API Keys**의 URL과 publishable(anon) 키를 `js/config.js`에 입력.
4. GitHub Pages(브랜치 `main`, 루트)로 배포.
5. (구글 캘린더 연결) script.google.com에서 새 프로젝트 → `Code.gs` 붙여넣기 → `TOKEN`을 긴 임의 문자열로 바꾸기 → 배포(웹 앱 · 실행: 나 · 액세스: 모든 사용자) → 앱 설정에 웹앱 URL과 같은 TOKEN 입력.

> publishable/anon 키는 공개용 키입니다. 데이터는 RLS(승인된 멤버만 접근)로 보호됩니다.
